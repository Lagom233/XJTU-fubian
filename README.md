# 复变研习室

复变函数与积分变换复习网页。包含八章、84 个题型和 179 道习题详解。

## 安卓手机和平板

用 Chrome 打开发布地址。章节、公式索引、题型总表和分类练习支持直接切换。长公式可在公式区域内横向滑动。在手机上可以折叠当前章节的题型列表。

第一次从 HTTPS 地址联网打开时，网页会在支持 Service Worker 的浏览器中缓存复习内容。缓存成功后，断网也能重新进入网页。若 Chrome 菜单显示「添加到主屏幕」或「安装应用」，可以从桌面图标进入。

作答记录、收藏和学习进度保存在访问网页的浏览器中。不同设备各自记录。

## 发布到 GitHub Pages

将本目录内容放在公开仓库的 main 分支根目录。在仓库的 Settings → Pages 中，将 Source 设为 Deploy from a branch，选择 main 和 /(root)，点击 Save。发布完成后，Pages 设置会显示该站点的 HTTPS 地址。

项目使用相对路径，可以部署到 GitHub Pages 的仓库子路径。网页无构建步骤，电脑端也可以双击 index.html 打开。
