# 复变研习室

复变函数与积分变换期末复习手册，涵盖复变函数、傅里叶变换和拉普拉斯变换，共 **8 章、84 个题型、179 道习题详解**。

**[在线打开](https://lagom233.github.io/XJTU-fubian/)** · **[下载电脑版离线包](https://github.com/Lagom233/XJTU-fubian/archive/refs/heads/main.zip)**

## 开始复习

- **按章节学**：从「学习总览」进入对应章节。记公式用「公式速看」，想弄清适用条件和易错点就切到「详细精讲」。
- **考前按题型刷**：打开「题型总表」，选择「考频优先」或「有原卷例题」，直接进入对应题型。
- **先做题，再看解答**：在「分类练习」里先写草稿。卡住了可以点「查看提示」，做完再点「查看完整解答」核对推导。想重做的题可以加入「复习清单」。

## 在电脑、手机和平板上使用

| 设备 | 怎么打开 | 怎么离线用 |
| --- | --- | --- |
| **电脑（Windows、macOS、Linux）** | 用 Chrome、Edge 或 Firefox 打开在线版 | 下载上方 ZIP，完整解压后双击 `index.html`。在线版打不开时也可以用这个方式。 |
| **安卓手机和平板** | 用 Chrome 打开在线版。手机可折叠章节题型列表，长公式可在公式区域内横向滑动。 | 首次联网打开并等待缓存成功后，可以断网再次进入。Chrome 菜单如有「安装应用」或「添加到主屏幕」，也可从桌面进入。 |

作答草稿、收藏和掌握进度保存在当前浏览器中。换设备或换浏览器后，进度单独记录。
