# 复变研习室

复变函数与积分变换复习网页，包含八章、84 个题型和 179 道习题详解。

[打开复变研习室](https://lagom233.github.io/XJTU-fubian/)

## PC（Windows、macOS、Linux）

用 Chrome、Edge 或 Firefox 打开上方网址。鼠标和键盘均可使用章节目录、公式索引、分类练习和互动图。

需要完全离线时，从仓库 **Code → Download ZIP** 下载并解压，双击根目录的 `index.html`。公式、题目和分步解答都在本地文件里。

## 安卓手机和平板

用 Chrome 打开同一网址。手机上可折叠本章题型，长公式可以在公式区域内横向滑动。平板支持横屏阅读。

首次联网打开后，支持 Service Worker 的浏览器会缓存页面。缓存成功后，即可断网再次打开同一网址。Chrome 菜单出现「添加到主屏幕」或「安装应用」时，也可通过桌面图标打开。

作答记录、收藏和学习进度保存在当前设备的浏览器中，各设备单独记录。

## GitHub Pages

发布源为 `main` 分支的 `/(root)`。页面、图标和离线缓存使用相对路径，可在仓库子目录中运行。项目无需构建。
